Rules

  • No emoji. Not for bullets, not for status, nowhere.
  • No unicode character used as an icon. No ✓, no ★, no arrow as a section mark. The only marks that belong to the system are · – — → (money flow only) and × (the MOIC unit).
  • An icon is functional and secondary. It supports a label; it never carries the message of a slide on its own, and it is never decoration.
  • One geometry. 24 px box, 1.5 stroke, no fill, currentColor. The interface theme is the same geometry as the React package @neonglow/icons; verify.py fails if the two drift apart.
  • Check before you deliver. X.check_icons(deck_html) reports an unknown name, an emoji, or a unicode character used as an icon.
