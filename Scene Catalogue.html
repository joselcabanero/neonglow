Rules

  • A scene gives context a chart cannot — the plant, the lab, the farm, the site. Never use one as decoration, and never use one when a number would say it better.
  • Grey by default. The accent marks the one element the slide is about, and only when the slide names it. Leave accent=None on a divider.
  • No glass, no blur, no transparency. Glazing is drawn as an open frame of hairlines, so what is inside still reads. Solid fills only, as everywhere else in the system.
  • A scene is a diagram, not imagery. It is built from the same flat fills as a chart, which is why it is allowed where a photograph is not.
